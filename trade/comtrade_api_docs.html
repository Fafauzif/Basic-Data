API documentation

Get UN Comtrade data straight into your own programs: what each API offers, how to call it, and examples to copy.

Get started

  1. Get a subscription key

    The public API needs no key. The others need a subscription key, free with any account, from My API portal.

    Log in

  2. Send the key with each request

    Put it in this request header:

    Ocp-Apim-Subscription-Key: your subscription key

    Or add it to the address as subscription-key=

  3. Try a first request

    This one needs no key: open it in your browser, or call it from your program.

    GET https://comtradeapi.un.org/public/v1/preview/C/A/HS?reporterCode=36&period=2023&partnerCode=0&cmdCode=TOTAL&flowCode=X

API products

  • Public API

    Previews of trade data (up to 500 rows), data availability, releases and reference lists, with no key.

    No key needed 8 endpoints

  • Bulk API

    Complete datasets as compressed files, one per reporter and period.

    Premium See the subscription plans

  • Async API

    Large queries prepared in the background; you get an email when the file is ready.

    Premium See the subscription plans

Log in to see the APIs that come with your subscription. Log in

Try it out

The interactive console (Swagger UI) sends requests from this page and shows the answers. Choose an API at the top, open an endpoint, then Try it out; for keyed APIs, enter your key under Authorize.

The console is a third-party tool, in English, and not fully accessible: everything it describes is also in the reference below.

Public API

Free API to preview trade data. Results are limited to 500 records. No subscription key required. See examples at https://unstats.un.org/go/498d8e

Address
https://comtradeapi.un.org/public/v1
Subscription key
Not needed
GET /preview/{typeCode}/{freqCode}/{clCode}

Get Trade Data (limited selection)

Parameters of /preview/{typeCode}/{freqCode}/{clCode}
Name Where Required What it is
typeCode In the path Yes Type of trade: C for commodities and S for service Values: C, S
freqCode In the path Yes Trade frequency: A for annual and M for monthly Values: A, M
clCode In the path Yes Product classifications: HS, SITC, BEC (for goods) or EBOPS (for services). Values: HS, H6, H5, H4, H3, H2, H1, H0, S4, S3, S2, S1, BE, BE5, EB, EB10, EB02, EBS
reporterCode In the query No Reporter code (Possible values are code of the countries separated by comma (,))
period In the query No Year or month. Year should be 4 digit year. Month should be six digit integer with the values of the form YYYYMM. Ex: 201002 for 2010 February. Maximum 1 period for preview
partnerCode In the query No Partner code (Possible values are code of the countries separated by comma (,))
cmdCode In the query No Commodity code. Maximum 1 commodity code for preview
flowCode In the query No Trade flow code. Multi value input should be in the form of csv (Codes separated by comma (,)) Allowed values (case-insensitive): M, X, RX, RM, MIP, XIP, MOP, XOP, MIF, XIF, DX, FM. Omit to not filter.

Example request

GET https://comtradeapi.un.org/public/v1/preview/C/A/HS?reporterCode=36&period=2023&partnerCode=0&cmdCode=TOTAL&flowCode=X

GET /getMBS

The MBS data API gives users access to historical time series of MBS trade tables, notably Tables 38 and 35. Data availability and frequency of update depend on data series. T35 Total trade - value (1946-) T38 Conversion factors (1946-)

Parameters of /getMBS
Name Where Required What it is
series_type In the query No Combination of table number, frequency, type of measurement and currenty. T35.Q.V.$ T35.A.V.$ T38.Q.CF. T38.A.CF. T35.M.V.$ T38.M.CF. Values: T35.Q.V.$, T35.A.V.$, T38.Q.CF., T38.A.CF., T35.M.V.$, T38.M.CF.
year In the query No Reference year (default = any):The reference year of period. As an example: 2015,2016
country_code In the query No Country code (Possible values are code of the countries separated by comma (,))
period In the query No Year or month. Year should be 4 digit year. Month should be six digit integer with the values of the form YYYYMM. Ex: 201002 for 2010 February. Multi value input should be in the form of csv (Codes separated by comma (,))
period_type In the query No data set frequency: Valid values: A Annual Q Quarterly M Monthly Values: A, Q, M
table_type In the query No (default = any) MBS Table numbers: MBS and ITSY table identifier. Values: T35, T38
format In the query No Output format (default = json): Valid value are json, txt or csv Values: csv, txt, json

Example request

GET https://comtradeapi.un.org/public/v1/getMBS?series_type=T35.A.V.%24&year=2023&country_code=36&period=2023&period_type=A&table_type=T35

Answers

  • 200 Success (JSON by default; CSV/TXT when format is set)
  • 400 Invalid or missing parameters.
  • 500 Unexpected server error.
