F. COLUMN NOTE ON THE EXPORT (important, no speculation)
The /export_excel file has exactly these 12 columns:
Kode HS, Nama Perusahaan, Kabupaten/Kota, Provinsi, Produk, Spesifikasi,
Kelompok Barang, Nilai TKDN (%), Nilai BMP (%), Nilai TKDN + BMP (%), LVI,
Tanggal Kadaluarsa Sertifikat.
It does NOT contain a certificate number or an issuance date, so the export is
a recap of certificate rows, not the certificate master record. Certificate
numbers are only visible in the interactive /sertifikat UI, which is
client-side only (item B/C above).
